# Mz悬浮球 (MzFloatBall)

Android 悬浮球工具，通过输入法模式直接操作文本框，支持所有 App（包括微信）。

## 功能

- ✅ **智能切换输入法** — 点悬浮球切换到 Mz 输入法，再点切回原来的输入法
- ✅ **复制/粘贴/剪切/全选** — 通过 InputConnection 直接操作文本
- ✅ **撤销/重做** — 支持多步撤销重做
- ✅ **悬浮球可拖动** — 支持拖动和自动贴边
- ✅ **透明度可调** — 设置面板调节悬浮球透明度
- ✅ **自动贴边延迟** — 可配置松手后贴边的延迟时间

## 安装

1. 从 [Releases](../../releases) 下载最新 APK
2. 安装后打开 App
3. 到「设置 → 管理键盘」开启 Mz 悬浮球输入法
4. 点击「启动悬浮球」

## 权限

| 权限 | 用途 |
|------|------|
| 悬浮窗权限 | 在其他 App 上显示悬浮球 |
| 输入法权限 | 直接操作文本框 |

## 使用方式

1. 在任意 App 的输入框里
2. **点悬浮球** → 自动切到 Mz 输入法（悬浮球变绿）
3. 键盘上点复制/粘贴/剪切/全选/撤销/重做
4. **再点悬浮球** → 自动切回原来的输入法

## 技术栈

- Kotlin + AndroidX
- WindowManager (悬浮窗)
- InputMethodService (输入法模式)
- InputConnection (直接操作文本)

## 签名

Release 版本使用固定签名密钥（`mzfloatball-release.jks`），可直接覆盖安装升级。
